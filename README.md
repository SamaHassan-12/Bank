# Loan Data Analysis Project

## Project Overview

This project focuses on analyzing loan data and preparing it for further analysis and visualization.

The project includes the original dataset before cleaning, the cleaned dataset, and a general description of the dataset and its data types.

## Data Cleaning

The cleaning process includes:

- Checking data types
- Checking missing values
- Checking duplicated rows
- Handling missing values
- Converting columns to appropriate data types
- Removing or correcting inconsistent data
- Preparing the dataset for analysis
